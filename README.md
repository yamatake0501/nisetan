# ニセタン 🎮

英単語学習アプリ「モチタン」風の英単語落下ゲーム。大学入試〜TOEIC 800点レベルの単語を、ゲームを通じて予習→プレイ→復習のサイクルで習得します。

## レベル分け

ホーム画面で3つのレベルを選べます。習得状況・ハイスコアはレベルごとに記録されます。

| レベル | 目安 | 収録語数 |
|--------|------|----------|
| 大学入試 | 入試の必須単語 | 47語 |
| TOEIC 600 | ビジネス基礎 | 51語 |
| TOEIC 800 | ハイスコア狙い | 101語 |

出題される単語もダミーの選択肢も、選んだレベル内から選ばれます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

1. **予習** — プレイ前に今回出題される12語のリストを確認。「意味を隠してテスト」でセルフチェックもできます（タップで意味を表示）。
2. **プレイ（50秒）** — 3つのレーンから時間差で英単語が落下。一番下にいる単語がターゲットになり、画面下の3択から正しい日本語の意味を選びます。
   - 正解: **+100pt**（単語が消える）
   - 不正解: **-50pt**
   - 地面まで落下: **-50pt**
3. **復習** — 結果画面で間違えた単語を確認。不正解・落下した単語は**次回のプレイで優先的に再出題**されます。

## 機能

- 大学入試〜TOEIC 800点レベルの英単語 199語収録（`js/words.js`）
- 3段階のレベル分け
- 間違えた単語の自動再出題（localStorage に保存）
- レベルごとの習得済み・復習待ち・ハイスコアの記録
- スマホ対応のレスポンシブUI
