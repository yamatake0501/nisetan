# ニセタン 🎮

英単語学習アプリ「モチタン」風の英単語落下ゲーム。大学入試〜TOEIC 800点レベルの単語を、ゲームを通じて予習→プレイ→復習のサイクルで習得します。

## レベル分け

ホーム画面で4つのレベルを選べます。習得状況・ハイスコアはレベルごとに記録されます。

| レベル | 目安 | 収録語数 |
|--------|------|----------|
| 大学入試 | 入試の必須単語 | 97語 |
| TOEIC 600 | ビジネス基礎 | 99語 |
| TOEIC 700 | 実務レベル | 102語 |
| TOEIC 800 | ハイスコア狙い | 180語 |

出題される単語もダミーの選択肢も、選んだレベル内から選ばれます。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

1. **予習** — プレイ前に出題順の先頭20語のリストを確認。出題はこのリストの上から順に続きます。「意味を隠してテスト」でセルフチェックもできます（タップで意味を表示）。
2. **プレイ（50秒）** — 3つのレーンから時間差で英単語が落下します。各レーンは独立していて、それぞれの一番下の単語が回答対象になるため、**最大3つの単語を同時に回答**できます。回答する（または落下する）と**すぐに次の単語が落ち始める**ので、問題間の待ち時間はありません。画面下にレーンごとの3択が表示され、正しい日本語の意味を選びます。出題数の上限はなく、50秒間シームレスに出題され続けます。
   - 正解: **+100pt** ＋ スピードボーナス（早く答えるほど最大+100pt）、さらに連続正解でコンボ倍率アップ（連続正解1つにつき+10%、最大×3）
   - 不正解: **-50pt**（コンボはリセット）
   - 地面まで落下: **-50pt**（コンボはリセット）
3. **復習** — 結果画面で間違えた単語を確認。不正解・落下した単語は**次回のプレイで優先的に再出題**されます。

ゲーム終了後、そのプレイのスコアがレベルごとの**ランキング上位5件**に入ればホーム画面の「🏆 ランキングを見る」から確認できます。効果音はホーム画面・ゲーム画面右上の🔊ボタンでオン・オフを切り替えられます。

## 機能

- 大学入試〜TOEIC 800点レベルの英単語 478語収録（`js/words.js`）
- 4段階のレベル分け
- 3レーン同時進行・同時回答が可能な出題システム
- 即答スピードボーナス＋連続正解コンボによるスコアリング
- 効果音（Web Audio APIで合成、音声ファイル不要）とオン・オフ切り替え
- 発音読み上げ（Web Speech API）— 正解時と単語クリック時に英単語を音声で再生
- 正解時のパーティクル演出、コンボ・スコアの弾む演出、不正解時のレーン揺れ、落下時の地面フラッシュなど演出を強化
- レベルごとのローカルランキング（上位5件、この端末に保存）
- 間違えた単語の自動再出題（localStorage に保存）
- 苦手単語のミス回数トラッキングと一覧画面
- レベルごとの習得済み・復習待ち・ハイスコアの記録
- スマホ対応のレスポンシブUI
