# ニセタン 🎮

英単語学習アプリ「モチタン」風の英単語落下ゲーム。TOEIC 800点以上レベルの単語を、ゲームを通じて予習→プレイ→復習のサイクルで習得します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（ビルド・サーバー不要）。

1. **予習** — プレイ前に今回出題される12語のリストを確認。「意味を隠してテスト」でセルフチェックもできます（タップで意味を表示）。
2. **プレイ（50秒）** — 3つのレーンから時間差で英単語が落下。一番下にいる単語がターゲットになり、画面下の3択から正しい日本語の意味を選びます。
   - 正解: **+100pt**（単語が消える）
   - 不正解: **-50pt**
   - 地面まで落下: **-50pt**
3. **復習** — 結果画面で間違えた単語を確認。不正解・落下した単語は**次回のプレイで優先的に再出題**されます。

## 機能

- TOEIC 800点以上レベルの英単語 100語収録（`js/words.js`）
- 間違えた単語の自動再出題（localStorage に保存）
- 習得済み・復習待ち・ハイスコアの記録
- スマホ対応のレスポンシブUI

## ファイル構成

```
index.html      画面構成
css/style.css   スタイル
js/words.js     単語データ（TOEIC 800+ / 100語）
js/game.js      ゲームロジック・学習データ管理
```
